# ⚔️ IGRIS — Shadow Knight AI Assistant

> *«Я всегда буду рядом, Сэр.»*

**IGRIS** — персональный AI-ассистент, вдохновлённый верным рыцарем-тенью Игрисом из манхвы *Solo Leveling*.
Он работает локально на вашем компьютере, обращается к вам «Сэр» и готов помочь в любой задаче —
от ответов на вопросы до наблюдения за экраном и генерации медиа.

---

## 🎯 Возможности

| Модуль | Описание |
|--------|----------|
| 🧠 **AI-мозг** | Мультишаговое мышление, использование инструментов (function calling), память |
| 🎙️ **Голос** | Wake-word «Игрис», распознавание речи, синтез речи (Edge TTS) |
| 👁️ **Экран** | Наблюдение за экраном, анализ скриншотов, фильтры приватности |
| 🔐 **Безопасность** | PIN-код, шифрование Vault, подтверждение опасных действий |
| 🎨 **Медиа** | Генерация изображений и видео (Pollinations AI) |
| ⏱️ **Фокус** | Pomodoro-таймер, блокировка уведомлений |
| 📊 **Аналитика** | Статистика использования, продуктивность |
| 💾 **Сниппеты** | Сохранение и поиск полезных фрагментов |

### Режимы работы

- **⚔️ Combat** — все системы активны, максимальная производительность
- **🛡️ Guard** — стандартный режим, голос + экран
- **💤 Sleep** — минимальное потребление, только прямые обращения

## 📦 Установка

### Требования

- Windows 10/11 (64-bit)
- Python 3.10+ ([скачать](https://python.org/downloads/))
- Groq API ключ ([получить бесплатно](https://console.groq.com/keys))

### Пошаговая установка

```
1. Скачайте/клонируйте проект
2. Запустите setup.bat (двойной клик)
3. Откройте config.json и добавьте API ключи
4. Запустите: venv\Scripts\python main.py
```

Или вручную:

```bash
# Создание окружения
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux/Mac

# Установка зависимостей
pip install -r requirements.txt

# Копирование конфига
copy config.example.json config.json   # Windows
cp config.example.json config.json     # Linux/Mac

# Запуск
python main.py
```

## ⚙️ Конфигурация

Все настройки в файле `config.json`.

### API ключи

| Сервис | Где получить | Обязательно |
|--------|-------------|-------------|
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | ✅ Да |
| Weather API | [openweathermap.org](https://openweathermap.org/api) | ❌ Нет |
| News API | [newsapi.org](https://newsapi.org/) | ❌ Нет |

> 💡 Рекомендуем добавить 3-5 Groq ключей для ротации при rate-limit'ах.

### Основные параметры

```jsonc
{
  "groq_api_keys": ["gsk_...", "gsk_..."],  // 1-5 ключей
  "model": "llama-3.3-70b-versatile",       // модель Groq

  "voice": {
    "wake_word_enabled": true,    // голосовая активация
    "tts_voice": "ru-RU-DmitryNeural"  // голос синтеза
  },

  "screen": {
    "enabled": true,              // наблюдение за экраном
    "interval_seconds": 30        // интервал скриншотов
  },

  "security": {
    "level": "standard",          // minimal / standard / paranoid
    "confirmation_mode": "smart"  // always / smart / never
  }
}
```

## 🚀 Использование

### Веб-интерфейс

После запуска откройте `http://localhost:3000` в браузере.

### Голосовое управление

1. Убедитесь, что `voice.wake_word_enabled: true`
2. Скажите **«Игрис»** и дождитесь звукового сигнала
3. Произнесите команду

### Чат-команды

- Просто пишите на естественном языке
- IGRIS сам выберет нужные инструменты
- Для опасных действий запросит подтверждение

### Примеры

```
> Который час?
> Сделай скриншот экрана
> Запусти таймер на 25 минут
> Переключись в боевой режим
> Запомни: встреча завтра в 15:00
> Что ты помнишь о встречах?
```

## 🔐 Безопасность

- **PIN-код** — защита от несанкционированного доступа
- **Vault** — шифрование чувствительных данных (AES-256)
- **Подтверждения** — опасные действия требуют одобрения
- **Фильтры приватности** — экран-наблюдатель пропускает банкинг, пароли
- **Локальность** — все данные хранятся только на вашем ПК
- **Ротация ключей** — автоматическое переключение при rate-limit

### Уровни безопасности

| Уровень | Описание |
|---------|----------|
| `minimal` | Без подтверждений, минимальные проверки |
| `standard` | Умные подтверждения для опасных действий |
| `paranoid` | Подтверждение каждого действия, полное логирование |

## ❓ FAQ

**Q: IGRIS бесплатный?**
A: Да! Нужен только бесплатный Groq API ключ.

**Q: Мои данные отправляются куда-то?**
A: Только текстовые запросы к Groq API для генерации ответов. Скриншоты, файлы и пароли остаются локально.

**Q: Какие модели поддерживаются?**
A: Все модели Groq: LLaMA 3.3 70B, Mixtral, Gemma и другие.

**Q: Можно ли использовать на Mac/Linux?**
A: Да, но setup.bat только для Windows. На Linux/Mac используйте ручную установку.

**Q: Как добавить свои инструменты?**
A: Зарегистрируйте их через `agent.tool_registry.register()` в любом модуле.

**Q: Wake-word не работает, что делать?**
A: Убедитесь, что микрофон доступен и `voice.wake_word_enabled: true` в конфиге.
